# ⚡ JavaScript — ওয়েবসাইটের মস্তিষ্ক

ভাবো —  
একটা মানুষ আছে  
দেখতেও সুন্দর  
কিন্তু নড়াচড়া করতে পারে না  
কথা বলতে পারে না  
কিছুতে রেসপন্স দেয় না  

ঠিক সেইরকম একটি ওয়েবসাইট হয় যদি **JavaScript না থাকে**।

HTML দেয় কাঠামো  
CSS দেয় রূপ  
কিন্তু **JavaScript দেয় প্রাণ** 🧠

---

## 📜 JavaScript এর জন্ম কাহিনি

১৯৯৫ সাল।  
একটি কোম্পানি — **Netscape**  
তারা চাইছিল ওয়েবসাইটকে আরও ইন্টার‌অ্যাকটিভ বানাতে।

একজন প্রোগ্রামার মাত্র **১০ দিনে** একটি ভাষা তৈরি করেন।  
তার নাম — **Brendan Eich**।

এই ভাষাটার নাম দেওয়া হয় —  
> **JavaScript**

কারণ মানুষ যেন ভয় না পায় এবং সহজে শিখতে আগ্রহী হয়।

---

## 🤔 JavaScript কেন দরকার?

ধরো তুমি একটি দরজা বানালে (HTML)  
তাতে সুন্দর রঙ দিলে (CSS)  
কিন্তু দরজা খুলবে না  

তাহলে কী হবে?

JavaScript দরজায় **হ্যান্ডেল** লাগায়।

JavaScript ছাড়া —
- বাটনে ক্লিক কাজ করবে না  
- ফর্ম সাবমিট হবে না  
- পপআপ খুলবে না  
- ডাটা লোড হবে না  

---

## 🌍 JavaScript ছাড়া ওয়েবসাইট কেমন?

JavaScript ছাড়া ওয়েবসাইট হবে —
- ফেসবুক স্ক্রল করবে না  
- ইউটিউব ভিডিও চলবে না  
- লগইন কাজ করবে না  
- কিছুই ক্লিক করলে রেসপন্স আসবে না  

মানে — **একটা পোস্টার, একটা অ্যাপ নয়**

---

## 🧠 JavaScript দিয়ে কী করা যায়?

JavaScript দিয়ে তুমি পারো —
- Button click detect করা  
- Login system বানানো  
- Game তৈরি করা  
- App তৈরি করা  
- Calculator বানানো  
- Form validation  
- API call  
- Animation control  
- Dark mode toggle  

আজকের Facebook, Instagram, YouTube — সব JavaScript দিয়ে চলে।

## 🧩 একটি ছোট JavaScript উদাহরণ

```html
<button onclick="sayHello()">Click Me</button>

<script>
function sayHello() {
  alert("Hello! JavaScript is working 🎉");
}
</script>
```

এই বাটনে ক্লিক করলেই মেসেজ দেখাবে।  
এইটাই JavaScript এর শক্তি।
